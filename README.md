# VOYAGER STAGE

5명의 안무, 대형, 카메라를 편집하고 음악을 포함한 프리비즈 영상을 만드는 브라우저 앱입니다. 업로드한 에셋은 브라우저에서 처리하며 외부 생성형 AI나 유료 API가 필요하지 않습니다.

## 시작

Windows에서는 `실행.cmd`를 더블클릭합니다. 의존성이 설치된 이 작업 폴더에서 로컬 서버를 시작하고 기본 브라우저를 엽니다. Node.js 22.13 이상이 필요합니다.

다른 컴퓨터에서는 Node.js와 pnpm을 설치하고 다음 명령을 실행합니다.

```sh
pnpm install
pnpm dev
```

터미널에 표시된 로컬 주소로 접속합니다. Chrome 또는 Edge 데스크톱을 권장합니다. 작은 화면에서는 상단의 라이브러리/인스펙터 버튼으로 패널을 엽니다. 뷰포트의 확대 아이콘으로 무대를 크게 볼 수 있습니다.

## 첫 영상 만들기

### 마우스로 편집하기

- 타임라인 위의 재생 헤드 또는 시간 눈금을 좌우로 드래그하면 그 시간의 포즈를 바로 확인할 수 있습니다. 기본은 프레임 단위 탐색이고, Shift를 누르면 비트에 맞춥니다. 재생 중 끌면 잠시 멈췄다가 놓은 위치에서 이어서 재생합니다.
- 모션 클립 막대를 좌우로 드래그해 시작 시간을 옮깁니다. 클립을 클릭하고 **Delete** 또는 Backspace를 누르면 해당 클립만 삭제합니다. **Ctrl+Z**로 되돌리고 **Ctrl+Shift+Z**로 다시 실행합니다. 텍스트 입력 중에는 클립이 삭제되지 않습니다.
- 무대와 타임라인 사이의 가로 경계선을 위아래로 끌어 높이를 조절합니다. 아래로 내리면 무대가 커집니다. 좌우 세로 경계선을 끌면 라이브러리와 인스펙터 너비를 바꿀 수 있습니다. 작은 창에서는 패널을 연 상태에서 바깥 경계선을 끕니다.
- 경계선을 더블클릭하면 해당 패널을 기본 크기로 되돌립니다. 경계선을 키보드로 선택한 뒤 방향키로 미세 조절할 수도 있습니다. 패널 크기는 현재 브라우저에 자동 저장됩니다. 타임라인을 작게 줄였을 때는 트랙 영역을 세로로 스크롤하며, 시간 눈금은 위에 고정됩니다.

### 색상·길이·위치 프레임

- 몸체 기본 색상은 EUNO 파랑, SEOWOO 보라, JIGYEOM 민트, IHYUN 주황, DOKYEONG 분홍입니다. 멤버를 선택하고 인스펙터의 **캐릭터 색상**으로 변경합니다. 기본 마네킹과 업로드한 FBX 모두 적용됩니다.
- 클립을 선택한 뒤 **왼쪽/오른쪽 끝의 손잡이**를 드래그해 길이를 조절합니다. 왼쪽 트림은 소스 시작 시간도 맞춥니다. 가운데를 드래그하면 길이를 유지한 채 이동합니다. 비트 스냅을 끄면 더 세밀하게 조절할 수 있습니다.
- 뷰포트의 **X/Y/Z** 버튼 또는 키보드 X/Y/Z로 우측/상단/정면 직교 보기로 즉시 바꿉니다. Shift를 함께 누르면 반대편입니다. **P 버튼**은 원근 보기입니다. Numpad 1/3/7은 정면/우측/상단, Numpad 5는 현재 구도를 유지하며 원근/직교를 전환합니다. 저장한 카메라 키는 투영 방식과 줌도 함께 보관합니다.
- 인스펙터에서 멤버의 위치 XYZ, 회전 XYZ, 크기 XYZ, 색상, 표시 여부를 조절합니다. 숫자를 좌우로 끌면 연속 조절, Shift는 미세 조절, Ctrl은 간격 맞춤, 클릭 후에는 숫자 입력이 가능합니다. Esc로 취소하며 한 번의 드래그는 실행 취소 한 번으로 복원됩니다.
- 타임라인 **◆ 키프레임 열기**를 누르면 멤버/클립/무대/대형/카메라 키 트랙이 나옵니다. **I** 또는 **◆ 전체 키**는 선택 대상의 모든 변환을 현재 프레임에 저장합니다. 개별 ◆는 해당 속성만 저장합니다. **● 자동 키**를 켜면 숫자 편집도 키로 저장합니다. 끄면 기존 키에서는 그 키를 수정하고, 키가 없는 시간에서는 전체 움직임의 기준값을 조절합니다.
- 키 마름모를 드래그해 시간을 옮기고 선택 후 **Del**로 삭제합니다. 인스펙터에서 선택 키의 시간과 보간을 바꿀 수도 있습니다. 같은 속성의 같은 프레임에 옮기면 도착 키를 대체합니다. 멤버 키 트랙의 L/R/S/C/V는 위치/회전/크기/색상/표시 여부이며, 선택 클립에는 별도 위치 오프셋과 위치 키가 있습니다.
- 멤버 위치는 무대 좌표로 편집하며, 클립 위치는 대형에 더해지는 이동 오프셋입니다. 클립 위치 키는 클립 기준 시간에 저장되어 클립 이동·트림·분할을 따라갑니다. 트림 밖의 키는 보존되어 다시 늘리면 복원됩니다. 클립 경계에서 오프셋은 해당 클립의 페이드 설정을 따릅니다.
- **무대 → 무대 위치**는 5명 전체를 중앙/앞/뒤/좌/우로 옮깁니다. **군무 대형**은 V/일렬/두 줄/대각선/다이아몬드/역V 모양을 바꿉니다. 무대 전체 이동, 대형, 멤버 이동, 클립 이동은 서로 다른 트랙으로 저장됩니다.
- 대형의 **거리 기준으로 자연스럽게 연결**은 이동 거리에 맞춰 시간을 계산하고 출발·도착을 부드럽게 합니다. **기존 대형도 모두 부드럽게 연결**로 이미 있는 대형도 정리할 수 있습니다. 선택한 대형의 이동 시간과 보간은 개별 수정할 수 있습니다.

### 카메라와 숫자패드

- **카메라** 탭에서 위치 XYZ, 회전 XYZ, 화각, 줌, 투영을 편집하고 **◆ 현재 구도 저장**으로 키를 저장합니다. **저장된 카메라 따라가기**를 켜면 재생·출력에 적용됩니다. 뷰포트에서 마우스로 잡은 구도는 ◆로 저장하고, 숫자 필드 편집은 자동 키로 저장할 수 있습니다.
- 숫자패드 **1/3/7**은 정면/우측/상단, **Ctrl**을 함께 누르면 반대편입니다. **2/4/6/8** 회전, **Ctrl+2/4/6/8** 이동, **9** 반대 방향, **5** 원근/직교, **.** 선택 멤버 확대, **+/-** 줌, **/** 선택 멤버만 보기, **0** 저장한 카메라로 복귀입니다. 문자 X/Y/Z와 Shift 반대편도 지원합니다.
- 무대 변환은 군무 전체의 위치·회전·크기·표시 여부에 적용됩니다. 위치 프리셋과 군무 대형은 별도로 유지되어 멤버 키와 함께 사용할 수 있습니다. 카메라의 투영과 표시 여부는 키 지점에서 전환되고, 숫자 속성은 보간됩니다.

### 제작 순서

1. Space로 기본 5인 마네킹의 샘플 동작을 재생합니다. 샘플 3종은 직접 만든 절차적 동작이며 실제 Mixamo 모션으로 표시하지 않습니다.
2. 실제 안무는 Mixamo에서 **같은 캐릭터**를 기준으로 다운로드합니다. 첫 FBX는 **With Skin**이 필요합니다. 이후 모션은 동일한 캐릭터의 Without Skin도 지원합니다. FBX Binary, 30fps 파일부터 시험하세요.
3. FBX를 라이브러리에 놓습니다. 첫 스킨 포함 FBX가 5명의 기준 모델이 됩니다. 추가된 FBX의 **5명 적용**을 눌러 기본 샘플 클립을 교체합니다. FBX 캐릭터와 기본 샘플 모션을 혼합할 수 없습니다.
4. MP3 또는 WAV를 올리고 BPM과 비트 오프셋을 맞춥니다. 비트 스냅은 수동 BPM을 기준으로 합니다. 자동 BPM 검출은 없습니다.
5. 모션을 트랙으로 드래그합니다. 클립을 선택하고 시작, 길이, 소스 시작, 속도, 반복, 양끝 페이드를 편집합니다. 클립을 겹치고 페이드를 주면 Crossfade됩니다. 같은 소스의 겹친 클립도 별개로 평가합니다.
6. **무대**에서 현재 시간에 무대 위치와 군무 대형을 각각 추가합니다. 이동은 키의 시작 시간부터 설정한 이동 시간 동안 보간합니다. 멤버별 위치는 독립된 위치 트랙에서 편집합니다.
7. 카메라 구도를 잡고 키프레임을 저장합니다. **카메라 키프레임 따라가기**를 켜면 미리보기와 출력에서 적용됩니다. 끄면 현재 카메라를 고정합니다.
8. **영상 출력**에서 비율, 해상도, FPS, 구간, 음악 포함 여부를 선택합니다. 녹화하는 동안 탭을 열어 둡니다.
9. 프로젝트 메뉴의 **프로젝트 ZIP 저장**으로 FBX와 음악까지 백업합니다. JSON 저장은 에셋을 포함하지 않으며 다시 열고 같은 원본 파일을 업로드해야 합니다. 브라우저 저장은 현재 브라우저/사이트에 종속됩니다.

## 구현 범위와 제한

- React, TypeScript, Vite, Three.js, Zustand, Web Audio, IndexedDB, MediaRecorder를 사용합니다. 결정론적 장면 평가와 영상 출력을 위해 Three.js 렌더러를 React 안에서 직접 관리합니다.
- 5명의 스켈레톤을 독립적으로 복제하고 동일한 시간 함수로 모션, 무대·대형·개별 위치, 카메라를 계산합니다. 지오메트리는 공유하고 색상 머티리얼은 멤버별로 독립적으로 관리합니다.
- 동일한 캐릭터/기준 포즈의 Mixamo FBX가 지원 범위입니다. 서로 다른 체형의 범용 리타게팅과 임의 FBX 호환성을 보장하지 않습니다. 첫 애니메이션 클립을 사용하고 외부 텍스처는 필요하지 않습니다.
- 수평 Root Motion은 첫 위치가 아닌 기준 리그의 Hips 위치에 고정하고, 높이 변화는 유지합니다. 월드 이동은 대형 트랙에서 관리합니다. 발 고정, 지면 IK와 발 미끄러짐 보정은 없습니다.
- 충돌 경고는 중심 간 0.65m 미만의 근접 검사이며 신체 메시 전체 충돌 검사가 아닙니다. 개별 경로는 멤버·클립 위치 키로 편집합니다. 자동 연결은 시간과 가감속을 조절하며 충돌 회피나 곡선 핸들 편집은 없습니다.
- 녹화는 **실시간 MediaRecorder**입니다. 24/30FPS는 요청값이며 시스템이 느리면 프레임이 누락될 수 있습니다. 프레임 단위 오프라인 인코딩은 미지원입니다. WebM을 우선하고 인코더가 지원되면 MP4로 대체합니다. 별도 MP4 변환기는 없습니다.
- 9:16의 720/1080은 세로 픽셀 기준입니다. 출력 캔버스는 UI를 포함하지 않습니다.
- 오디오와 장면은 AudioContext 시계를 공유합니다. 전체 미리보기 속도를 바꾸면 음악의 음높이도 변합니다. 출력은 항상 1×입니다. 반복은 전체 프로젝트 구간 기준입니다.
- Low/Medium/High는 미리보기 픽셀 밀도를 조절합니다. 그림자와 후처리는 사용하지 않습니다. 특정 FPS는 보장하지 않습니다.
- 실행 취소/다시 실행은 최근 편집 40개를 유지합니다. 리소스 파일은 브라우저 메모리에 유지하며, 새 프로젝트를 열 때 이전 리소스를 해제합니다.
- Seedance에 직접 연결하거나 업로드하지 않습니다. 특정 외부 서비스의 업로드 규격/현재 버전과의 호환성은 검증하지 않았습니다.

## 검증

```sh
pnpm fixtures # 선택: 실제 FBX 통합 검사 자산 다운로드
pnpm test
pnpm build
```

테스트 25개는 시간 탐색·클립 편집·실제 FBX 복제뿐 아니라 변환 계층, 월드 좌표 역변환, 360도 회전·크기·색상·표시 키, 무대 위치 보간, 카메라 속성 저장, 자동 키, 드래그 실행 취소, 키 이동/삭제, 숫자패드 조작을 검사합니다. 실제 FBX 파일이 없으면 그 검사 하나만 건너뜁니다.

검증용 FBX는 저장소에 포함하지 않습니다. `pnpm fixtures`가 Three.js 공식 r180 예제에서 내려받습니다. 출처: https://github.com/mrdoob/three.js/tree/r180/examples/models/fbx . `Metronome-120bpm.wav`는 테스트용으로 생성한 120BPM 신호입니다.
